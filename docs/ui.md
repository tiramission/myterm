# UI/UX 设计规范

myterm 的界面语言：**干净、清爽、简约、现代**。本文是唯一权威，界面代码以它为准。

---

## 1. 设计立场

终端是专业工具，界面必须**退后一步**：用户 95% 的时间在看终端内容，外壳只负责定位与切换。

三条原则：

1. **终端优先**。画布占据绝大部分面积，chrome 只占必要的一行。任何装饰都不能挤压终端。
2. **结构表达层次**。用间距、分隔线、字重建立层级，而不是用颜色块、边框、阴影堆叠。
3. **一个焦点**。每个表面只有一个视觉重点；强调色（`primary`）只给"当前"和"主操作"，其余一律中性。

---

## 2. 布局骨架

```
┌──────────────────────────────────────────────────────┐
│ 标签栏 34pt：标签 · + · ⌄ ·············· 命令面板提示 │
├──────────────────────────────────────────────────────┤
│                                                      │
│                    终端画布（分屏）                    │
│                                                      │
├──────────────────────────────────────────────────────┤
│ 状态条 24pt：配置文件 ·············· 尺寸 · 设置      │
└──────────────────────────────────────────────────────┘
```

- **标签栏 34pt**：高度固定，`surface` 底色。标签之间 2pt 间隙，标签本身 28pt 高、圆角 6pt。
- **状态条 24pt**：极简，只有三段信息，`muted-foreground` 小字。不用 `border-t` 之上再加阴影。
- **画布**：`flex-1`，无内边距，无边框（焦点窗格用 1pt `primary` 描边，这是唯一允许的强调）。

分屏分隔线 **1pt**，颜色 `border`，不加额外间距。

---

## 3. 颜色（全部来自 `theme.json`）

| 用途 | Token | 说明 |
| --- | --- | --- |
| 窗口底 / 画布 | `background` | 终端配色方案覆盖画布，外壳用此 |
| 主文字 | `foreground` | |
| 次要文字 | `muted-foreground` | 状态条、描述、占位符 |
| 标签栏 / 状态条 | `card` | 比 background 略高一级的表面 |
| 浮层（菜单/面板/对话框） | `popover` | |
| 悬停 / 按下 | `accent` | 只用于行与按钮的交互态 |
| 强调 | `primary` | 焦点窗格描边、选中标记、主按钮 |
| 分隔 | `border` | 1pt，仅结构边界 |
| 成功 / 警告 | `success` / `warning` | 仅进程退出码 |

**禁止**：表现层出现任何 hex/rgb 字面量。配色方案色卡是数据，例外。

**禁止**：给卡片加阴影。阴影只给浮层（`shadow_lg`），且只给一层。

---

## 4. 字号与间距

字号只用三档：

| Token | 值 | 用途 |
| --- | --- | --- |
| `text_xs` | 12pt | 状态条、快捷键 chip、分组标签 |
| `text_sm` | 13pt | 正文、菜单行、设置行 |
| `text_lg` | 16pt | 面板标题（唯一的大字） |

间距只用五档（Tailwind 4pt 步进）：`gap_1`(4) `gap_2`(8) `gap_3`(12) `gap_4`(16) `gap_6`(24)。

关系规则：
- 同一控件内部 4pt；相邻控件 8pt；同一分组内 12pt；分组之间 24pt。
- 面板内边距 16pt；面板标题到内容 12pt。

**禁止**：`px(13.0)` 这类点值直接写在表现层（除 hairline、终端网格度量）。

---

## 5. 圆角与密度

| 元素 | 圆角 |
| --- | --- |
| 标签、行、按钮 | 6pt |
| 面板、菜单、浮层 | 8pt（= `radius`） |
| 快捷键 chip、色卡 | 4pt |

控件高度：图标按钮 26pt、标签 28pt、查找栏 32pt、菜单行 28pt（`py_1` + 13pt 文字）。

## 6. 组件层（`src/ui.rs`）

所有页面只组合这些，不各自重写样式：

| 组件 | 用途 |
| --- | --- |
| `menu_row` | 菜单行，hover/active 用 `accent` |
| `icon_button` | 方形图标按钮，带无障碍名 |
| `text_button` | 低强调文字按钮（状态条、面板关闭） |
| `primary_button` | 唯一主操作 |
| `setting_row` | 设置行：标签 + 右对齐勾选 |
| `section_label` / `panel_title` / `panel_subtitle` | 层级文字 |
| `shortcut_chip` | 快捷键 chip |
| `scheme_chip` | 配色方案色卡（数据色） |
| `popup_surface` | 浮层表面样式（圆角+边框+底色+阴影） |

---

## 7. 浮层：用 NSH 原生组件，不用绝对定位

这是本次重做的核心修正。

| 浮层 | 组件 | 理由 |
| --- | --- | --- |
| 命令面板 | `nsh_base::command` + `overlay` | 自带虚拟化、键盘导航、分组、快捷键显示、空状态 |
| 设置 | `nsh_base::sheet` | 自带 open/Escape/backdrop 关闭、动画、不超出窗口 |
| 右键菜单 | `overlay` + `anchor_point` | 在指针处，自动避让窗口边缘 |
| 查找栏 | 窗格内嵌（非浮层） | 不遮挡终端 |

**教训**：绝对定位的容器在 NSH 里不会把 `top`/`bottom` 变成高度约束，子元素也不会自动收缩；浮层内容一旦超出就被裁切。必须用 `overlay`（`position: fixed`，不随父级裁剪）或 `sheet`（自管布局）。

`scroll()` 需要父级有确定高度（`flex_1` 在受限容器内），否则内容尺寸不参与滚动计算。

---

## 8. 交互态

每个可交互元素必须有：

| 状态 | 表现 |
| --- | --- |
| 静息 | 无底色 |
| 悬停 | `accent` 底 |
| 按下 | `accent` 底（同悬停，不加缩放） |
| 焦点 | `primary` 1pt 描边（仅窗格与输入框） |
| 选中 | `primary` 的勾 / 文字色 |
| 禁用 | 不适用（当前无禁用项） |

**不依赖悬停**：所有操作都有键盘路径（命令面板或快捷键）。

---

## 9. 文案

- 命令用动词（新建标签、关闭窗格），目的地用名词（设置）。
- 会打开浮层的命令加 `…`（查找…、设置…）。
- 短标签不加句号；完整句子加全角句号。
- 报错说清发生了什么 + 下一步。

---

## 10. 无障碍

- 图标按钮必须有 `.label()`。
- 焦点顺序 = 视觉顺序。
- 状态不只靠颜色（退出码同时有文字说明）。
- 快捷键在所有入口一致显示。

---

## 11. 验收

- 深浅两种外观都检查。
- 125% / 150% 缩放检查（本机 150%）。
- 最小窗口 640×400 时 chrome 不挤压终端。
- 浮层在任何窗口尺寸下都不被裁切。
- 表现层零色值字面量（`grep -o "rgb(0x"` 为空）。
