## 1. 主张

在原有三条（标签在侧、窗格是卡片、chrome 随复杂度增长）之上，收敛为六条：

| # | 原则 | 它约束什么 |
| --- | --- | --- |
| P1 | **窗口要有名字** | 任务栏、Alt+Tab 读的是窗口标题；现在一律「myterm」 |
| P2 | **边界用线说，层级用明度说** | 卡片永远有一条 hairline；chrome 与卡片至少差 1.2:1 |
| P3 | **状态三重编码** | 形状、颜色、词三者至少取其二；颜色不是唯一线索 |
| P4 | **内容不被装饰压暗** | 焦点表达在 chrome 上，不盖在网格文字上 |
| P5 | **每个动作都有一条键** | 桌面用户用鼠标，键盘用户走命令面板；两条路到同一个结果 |
| P6 | **状态条只在有话时说** | 常驻 22px 只为偶尔看一眼不划算；空的就不画 |

## 3. 骨架（以原型为准）

### 3.1 顶栏（44px）

```
myterm   ~/myterm   ⎇ main          [⌘ 输入命令或搜索会话]   ▯ ▭ ＋  ⋯   – □ ✕
```

- **左**：工作区名（13/650）· 当前窗格目录（11，`text_3`，尾部省略）· 分支胶囊（10）。
- **中**：命令入口，`Ctrl+K`。它是所有命令的发现入口，鼠标用户唯一找得到的「全部功能」。
- **右**：向右分屏 / 向下分屏 / 新建标签 · 应用菜单（设置、关于、检查更新、主题、退出）· 窗口按钮。
- 空白处拖动窗口。窗口不设「拖动区占满整个中间」——命令入口占位后，剩下的空白仍可拖。

### 3.2 侧栏（238px / 56px）

**列表档**：工作区组头（名字 + 布局字形 + 计数）+ 会话行。

```
myterm                         3
  ● cargo run        ~/myterm
  ● cargo test       ~/myterm/crates/vt
  ○ ssh dev          ~
日志                           2
  ● nginx · access   ~/srv
  ✕ build            ~/srv
```

- 行高 42（密度可调 34 / 42 / 50）；第一行名字 12px，第二行目录 10px `text_3`。
- 行尾：状态词（仅「输出中 / 已退出」）+ hover 才出现的 `×`。
- 关闭：hover `×`、中键、`Ctrl+Shift+W`；正在输出的会话先确认，空闲的直接关并可撤销（§3.6）。
- 选中：整行 `surface`，名字 `text`；**不加左侧色条**。

**窄条档（56px）**：一个工作区一组（26px 字首块 + 会话块），当前工作区整组抬起；
会话块 30px，首字 + 右上角 5px 状态点，首字颜色按状态（在动=强调 / 退出=危险 / 空闲=`text_2`）。
窄条里没有 `×`：56px 放不下不会误触的关闭键，这条路交给命令面板和快捷键。

### 3.3 窗格

- 卡片：`bg` + 1px `stroke` + 圆角 12；多窗格时顶栏 30px（名字 · 目录 · 分支 + 悬停动作）。
- 焦点：卡片描边换强调色；其余卡片保持中性，**不压暗文字**。
- 单窗格不画窗格头——上下文交给顶栏。
- 缩放：窗格临时占满画布，按钮变「退出缩放」、状态条给出 `Esc 退出`；切焦点/关窗格/切标签都退出。
- 网格内缩 10（水平）/ 6（垂直），与窗格头共用左边线。

### 3.4 状态条（条件出现）

只在有事要说时出现，高度 26，说完就消失：

| 状态 | 文案 |
| --- | --- |
| 缩放中 | `已缩放 · Esc 退出` |
| 后台会话有新输出 | `2 个会话有新输出`（点击跳过去） |
| 更新可下载 | `更新 0.4.0 · 查看` |

静止时是 0（不占 26px）。会话数、分支、快捷键提示都不常驻：分支在顶栏，计数在侧栏组头，
快捷键在命令面板的属性上。

### 3.5 浮层

| 表面 | 触发 | 规则 |
| --- | --- | --- |
| 命令面板 | `Ctrl+K` | 命令 + 会话 + 主题；模糊过滤、↑↓、Enter、Esc。行右侧标键位 |
| 设置 | `Ctrl+,` / 齿轮 / 应用菜单 | 右侧 436px sheet，**遮罩 12%**（不是 55%），改了要当场看见；三页签：外观 / 终端 / 快捷键 |
| 关于 | 应用菜单 / 面板 / 设置页脚 | 居中卡片，只读：版本、依赖、安装状态、更新、GitHub |
| 查找 | `Ctrl+Shift+F` | 窗格内**占位**条（不浮在输出上），高亮全部命中 + `1/n`；Enter / Shift+Enter 上下条 |
| 关闭确认 | 关正在输出的会话/标签 | 说清后果：「它还在运行，关闭会结束这个进程」 |
| 撤销 | 关闭之后 | 右下角 6 秒，恢复整个布局树与焦点 |

### 3.6 关闭语义（三档，别混）

| 对象 | 鼠标 | 键盘 | 确认 |
| --- | --- | --- | --- |
| 窗格（会话） | 行尾 `×` / 中键 | `Ctrl+Shift+W` | 正在输出才问 |
| 标签（工作区） | 组头 `×` | `Ctrl+Shift+Q` | 组内有会话在跑才问，并报数量 |
| 窗口 | 标题栏 `✕` | `Alt+F4` | 标签或窗格数 > 1 时问；见 §6.2 |

关掉标签里最后一个窗格 = 关标签。全部关完 = 空状态「没有打开的会话 · 新建标签」，不是黑屏。

## 4. 视觉系统

### 4.1 表面（已落地，数值即实现）

| token | 深色 | 浅色 |
| --- | --- | --- |
| `bg` 网格 | `#101210` | `#FFFFFF` |
| `bg_soft` 外壳 / 顶栏 / 侧栏 | `#1A1D18` | `#E7EADF` |
| `surface` 抬起的行 / 胶囊 | `#22261E` | `#FFFFFF`（= 白，抬在 chrome 上） |
| `stroke` 描边 | `#33382D` | `#D2D6C6` |
| `text` / `text_2` / `text_3` | `#F2F5EC` / `#A6ADA0` / `#8A9281` | `#14170F` / `#555B4D` / `#656B5C` |
| `brand` | `#C6EE7A` | `#3F6B12` |

实测对比度（WCAG）：

| 关系 | 改前 | 现在 |
| --- | --- | --- |
| 卡片 vs 外壳 | 浅 1.10:1 / 深 1.05:1 | 浅 1.22:1 / 深 1.10:1 |
| 卡片描边 | 无 | 浅 1.48:1 / 深 1.56:1 |
| `text_3` on 外壳 | 浅 2.96:1 | 浅 4.52:1 / 深 5.28:1 |
| 状态词（满值 `text_3`） | 浅 3.70:1（0.8 折扣） | 浅 4.52:1 |

1.22:1 很轻，它配合 1px 描边才成立——去掉任一条，浅色模式就退回「看不出卡片」。
深色不再提亮外壳：靠 10px 间隙 + 1.56:1 的线；再亮会让窗框比终端还显眼。

### 4.2 类型、圆角、间距

- 类型：窗口标题 13/650；目录 mono 11；侧栏名字 12（选中 600）；栏头 11/500；状态词 10.5 满值；网格 mono 14（可配 12–20）。
- 圆角四档：4（kbd）/ 8（行、按钮）/ 10（胶囊）/ 12（卡片）。
- 间距六档：4 / 6 / 8 / 10 / 12 / 16 / 24，进一个 `space()`，不散在调用点。

### 4.3 强调色预算（4 处）

当前标签描边、当前窗格描边、可拖手柄、「有输出」状态。**应用标记改中性**，hover 才借用强调——
它是身份，不是「当前」。

## 5. 键位

`Ctrl+Shift` 命名空间是必须的：`Ctrl+W` 是 readline 删词、`Ctrl+N` 下一条历史、`Ctrl+F` 前移一个字符。
终端不能占用它们，`Ctrl+F` 也不行——所以查找是 `Ctrl+Shift+F`。

| 动作 | 键 | 说明 |
| --- | --- | --- |
| 新建标签 | `Ctrl+Shift+T` | 与 Windows Terminal 一致 |
| 关闭窗格 | `Ctrl+Shift+W` | 最后一个窗格时关标签 |
| 关闭标签 | `Ctrl+Shift+Q` | **保留现有语义**；退出走 `Alt+F4` / 应用菜单 |
| 切换标签 | `Ctrl+Tab` / `Ctrl+Shift+Tab` | 新增 |
| 直达标签 | `Ctrl+1..9`（9 = 最后一个） | 新增 |
| 重开刚关的标签 | `Ctrl+Shift+R` | 新增，栈深 10 |
| 左右分屏 / 上下分屏 | `Ctrl+Shift+D` / `Ctrl+Shift+E` | 不变 |
| 缩放窗格 | `Ctrl+Shift+Z` | 不变 |
| 侧栏档位 | `Ctrl+Shift+B` | 不变 |
| 主题 | `Ctrl+Shift+L` | 不变 |
| 查找 | `Ctrl+Shift+F`；`F3` / `Shift+F3` 上下条 | 新增 |
| 命令面板 | `Ctrl+K` | 新增 |
| 设置 | `Ctrl+,` | 新增 |
| 全选网格 | `Ctrl+Shift+A` | 新增 |
| 字号 | `Ctrl+=` / `Ctrl+-` / `Ctrl+0` | 新增 |
| 窗格导航 | `Alt+方向` | 不变，按几何而非按树 |
| 粘贴 / 复制 | `Ctrl+Shift+V` / `Ctrl+Shift+C` | 不变 |

原型是浏览器页面，额外接受 `Ctrl+F`（浏览器习惯）与 `Alt+1..9`（旧习惯），两者都映射到同一命令；
**产品键位以本表为准**。

## 6. 原型没覆盖、但必须实现的

### 6.1 会话快照与恢复

- 退出时写 `%APPDATA%\myterm\session.json`：标签结构、分屏树与比例、每个窗格的启动命令与 cwd、
  侧栏宽度与档位、主题、窗口 bounds。
- 启动**不自动恢复**，顶栏下出现提示带：`恢复上次的 3 个标签？` + `恢复` / `忽略`。
- 恢复的每个窗格重新 spawn shell，不保留输出——明确写在提示里，避免「恢复」被读成「回到当时」。
- 窗口越界时按当前屏幕 clamp。

### 6.2 关窗确认

- 标签或窗格数 > 1 → `还有 3 个窗格在运行`，动作 `仍然关闭` / `取消`；可勾「不再提示」。
- 单标签单窗格直接关。
- **不做进程存活检测**：ConPTY 下没有可靠判定，假装知道就是骗人；用快照兜底。

### 6.3 后台信号

| 事件 | 表面 | 文案 |
| --- | --- | --- |
| 非焦点窗格响铃（`\a`） | 标签行 8px 徽章 + 任务栏闪烁 | — |
| 非焦点命令结束且耗时 > 5s | 侧栏行尾 | `完成 12s` / `失败 · 1` |
| 进程退出 | 状态字形 + 行尾 | `已退出` |
| 更新可下载 | 应用菜单 + 状态条 | `更新 0.4.0` |

### 6.4 配置层

- `%APPDATA%\myterm\config.toml`；写入防抖 300ms；解析失败一律回落默认值，并在顶栏一次性提示
  `配置文件有误，已使用默认设置 · 查看`（点击打开所在目录）。
- 键：`font.family` / `font.size` / `font.line_height` / `font.cursor` / `font.blink` /
  `terminal.shell` / `terminal.scrollback` / `terminal.copy_trim` / `appearance.theme` /
  `appearance.accent` / `appearance.density`。
- 设置面板的每一项都对应一个键，不存不存在的东西。

### 6.5 窗口标题

OS 窗口标题 = `标签名 · 目录`（无标签时 `myterm`）。任务栏、Alt+Tab、窗口缩略图都只读它。
顶栏的文字是给人看的第二份，不是替代品。

## 7. 与 11-13 提案的差异（合并时的决定）

| 项 | 11-13 提案 | 现在 | 为什么 |
| --- | --- | --- | --- |
| 状态条 | 不做常驻 | **条件出现** | 会话数、分支、提示都不常驻；仅缩放/后台/更新时出现，静止 0px |
| 标题栏 | 中间放「标签名 + 目录」 | 顶栏放「工作区 + 目录 + 分支」；**OS 标题另设** | 两者都要：一个给眼睛，一个给任务栏 |
| 侧栏行高 | 30 | 42（密度 34/42/50） | 一行放不下「名字 + 目录 + 状态」，而目录是识别会话的关键 |
| 查找键 | `Ctrl+Shift+F` | 产品同左；原型额外收 `Ctrl+F` | 浏览器里没有 readline |
| 关标签键 | `Ctrl+Shift+Q` 让给退出 | **保留为关标签** | 已发布的行为不改；退出有 `Alt+F4` 和应用菜单 |
| 焦点表达 | 1px 描边 | 已落地 | 蒙雾已删除 |
| 窗口外沿 | 四边等距或全幅 | 现在上/左贴边、右/下 10 | 待定：最大化时应全幅（§8 P3） |
| 关闭确认 | 按「有没有进程」判断 | 按**会话是否在输出**判断 | 不假装能检测进程存活 |
| 会话恢复 | 启动后提示恢复 | 保留，并在提示里说明「不保留输出」 | 避免误解 |

## 8. 实施路线

**已完成（0.5.0）**：P0 与 P1 全部、P2 的关窗确认与窗口标题、P3 的强调色收敛；
详情看 CHANGELOG。下面保留的是当初的分期，供对照。

**P0 —— 让键盘和状态补齐（约 2 天）**
1. 键位：`Ctrl+Tab` / `Ctrl+1..9` / `Ctrl+Shift+F` / `Ctrl+,` / `Ctrl+=`。
2. 侧栏：任意行 hover 关闭、中键关闭、`Ctrl+Shift+W` 兜底关标签。
3. 状态三重编码：实心圆=有输出、空心圆=空闲、方块+叉=已退出；窄条 tooltip（全名 · 状态 · 目录）。

**P1 —— 三个新表面（约 1 周）**
4. 命令面板（`component::command`），命令里带上键位。
5. 查找（`vt` 已有搜索接口，接高亮层；占位条不浮层）。
6. 设置 sheet + `config.toml`（写入防抖、失败兜底）；先做外观与终端两页。
7. 关于卡片收敛：键位一览搬进设置。

**P2 —— 会话与窗口（约 1 周）**
8. 会话快照 + 恢复提示带。
9. 关窗确认 + 「不再提示」。
10. 后台信号（响铃徽章 + 任务栏闪烁 + 命令耗时）。
11. 窗口标题；标签重命名 / 右键菜单 / 拖拽重排。

**P3 —— 收尾**
12. 外沿策略：窗口化四边等距、最大化全幅（消除 L 形的中间态）。
13. 应用标记改中性色，强调色收敛到 4 处。

**测试**（与现有 `layout` / `vt` 同标准）：
- `config`：空文件 / 缺字段 / 未知字段 / 损坏 TOML → 默认值且不 panic；
- `session`：快照往返、越界 clamp；
- `keymap`：表驱动，键位无冲突；
- `find`：命中序号在回滚区前后都正确。

## 9. 明确不做

## 10. 验收

1. 新用户不读 README，能否找到「分屏」「改字号」「查找」？（命令面板 + 设置）
2. 「关闭」的三种粒度（窗格 / 标签 / 窗口）名称、确认、撤销是否一致？
3. 拿掉强调色，还能不能看出「当前标签、当前窗格、哪行被选中」？（形状与明度要独立成立）
4. 深浅两模式、100/125/150% 缩放、最小窗口 720×480 各走一遍。
5. 每个 hover 才出现的控件，是否都有键或菜单路径？
6. 11px 以上文字对各自底 ≥ 4.5:1；卡片与外壳 ≥ 1.2:1 且有 hairline。
7. 关窗、崩溃重开、配置损坏三种失败态各试一次。
